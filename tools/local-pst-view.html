          Pièces jointes
            
      
            
      
            
        
            Préparer un brouillon
            
        
            Le lien préremplit Outlook Web : destinataires, objet et texte seront présents dans l'URL et peuvent apparaître dans l'historique ou des journaux. Vérifiez les destinataires, notamment votre propre adresse.
            
        
            Il s'agit d'un nouveau message : le fil et les pièces jointes ne sont pas repris automatiquement. Téléchargez et joignez les fichiers nécessaires séparément.
            
        
            
        
        
        
        
        
        
            Ouvrir le brouillon dans Outlook Web
            
        
            Si le message est trop long ou si le préremplissage échoue, ouvrir Outlook Web sans préremplissage et copier les champs manuellement.
